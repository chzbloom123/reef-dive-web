## Code snippets
- Shader hash functions in `src/scene/caustics.js` and `src/shaders/noise.glsl.js` follow the "Hash without Sine"
  approach by Dave Hoskins (https://www.shadertoy.com/view/4djSRW), MIT License.
- 3D gradient noise in `src/scene/noise.js` implements Ken Perlin's published "Improved Noise" algorithm (2002).
